# Dev Playbook

## Standard Feature Flow

### 1. Define
What are we building in one sentence?

### 2. Scope
What files are involved?

### 3. Plan
Break into small steps (max 5)

### 4. Implement
Do one step at a time using diffs

### 5. Verify
Check behavior after change

### 6. Update Memory
After completion:
- update memory.md
- add entry under Recent Changes
